# True Employee Cost Calculator

## Purpose

Answer this question:

“What does this employee really cost my business per year?”

This calculator is broader than the Labor Burden Calculator.

Labor Burden focuses on productive-hour economics.
True Employee Cost focuses on total annual employer cost.

Primary audience:
U.S. contractors and home-service businesses.

## Core principles

- Avoid double-counting compensation or benefits.
- Distinguish direct compensation from employer-paid costs.
- User-entered tax, insurance, benefit, equipment, and overhead values are assumptions.
- Do not imply universal U.S. tax or benefit rates.
- All calculation logic must later live in a pure TypeScript function with no DOM access.
- Invalid inputs must return structured validation errors.
- This calculator should work for both hourly and salaried employees.

## Compensation mode

The user can choose:

1. Hourly employee
2. Salaried employee

### Hourly mode inputs

- Hourly wage
  - USD/hour
  - default: 30

- Paid hours per week
  - default: 40

- Paid weeks per year
  - default: 52

Annual base compensation =
hourly wage × hours/week × weeks/year

### Salary mode inputs

- Annual salary
  - USD/year
  - default: 70000

Annual base compensation =
annual salary

## Employer cost inputs

### Quick inputs

- Payroll taxes
  - percent of annual base compensation
  - editable user assumption

- Workers’ compensation
  - percent of annual base compensation
  - editable user assumption

- Health insurance
  - USD/year

- Retirement contribution
  - USD/year

### Advanced inputs

- Bonuses / commissions
  - USD/year

- Other benefits
  - USD/year

- Recruiting / hiring cost
  - USD/year or annualized planning value

- Training cost
  - USD/year

- Tools and uniforms
  - USD/year

- Phone / device cost
  - USD/year

- Vehicle allowance / employer vehicle cost
  - USD/year

- Software / licenses
  - USD/year

- Workspace / office allocation
  - USD/year

- Other annual employee costs
  - USD/year

## Calculations

Annual Base Compensation =
hourly calculation OR annual salary

Payroll Taxes =
annualBaseCompensation × payrollTaxRate

Workers Comp =
annualBaseCompensation × workersCompRate

Additional Cash Compensation =
bonusesAndCommissions

Benefits Cost =
healthInsurance
+ retirementContribution
+ otherBenefits

Operating Support Cost =
recruitingHiringCost
+ trainingCost
+ toolsUniforms
+ phoneDeviceCost
+ vehicleCost
+ softwareLicenses
+ workspaceAllocation
+ otherAnnualEmployeeCosts

Total Annual Employee Cost =
annualBaseCompensation
+ payrollTaxes
+ workersComp
+ additionalCashCompensation
+ benefitsCost
+ operatingSupportCost

Cost Multiplier =
totalAnnualEmployeeCost / annualBaseCompensation

Additional Employer Cost =
totalAnnualEmployeeCost - annualBaseCompensation

Additional Employer Cost Percent =
additionalEmployerCost / annualBaseCompensation × 100

Monthly Employer Cost =
totalAnnualEmployeeCost / 12

Weekly Employer Cost =
totalAnnualEmployeeCost / 52

If hourly mode:

Paid Hour Employer Cost =
totalAnnualEmployeeCost / annualPaidHours

## Optional revenue/productivity scenario

Include an optional input:

Expected annual revenue generated by employee
- USD/year
- default: blank / disabled until entered

If entered and > 0, calculate:

Revenue-to-Cost Ratio =
expectedAnnualRevenue / totalAnnualEmployeeCost

Contribution Before Shared Overhead =
expectedAnnualRevenue - totalAnnualEmployeeCost

Do not call this net profit.

Clearly state that shared company overhead, owner compensation, financing, tax, and other business costs may still remain.

## Primary result

Example:

“Your $70,000 employee costs about $94,350 per year.”

Secondary message:

“Every $1.00 of base pay costs your business $1.35.”

For hourly employees, wording should adapt naturally, for example:

“Your $30/hour employee costs about $76,000 per year.”

## Result breakdown

Show:

- Base compensation
- Payroll taxes
- Workers’ compensation
- Bonuses / commissions
- Benefits
- Operating support costs
- Additional employer cost
- Additional employer cost %
- Total annual employee cost
- Monthly employer cost
- Weekly employer cost
- Cost multiplier
- Paid hour employer cost, if hourly mode

If revenue input is provided, also show:
- expected revenue
- revenue-to-cost ratio
- contribution before shared overhead

## Validation

Reject or flag:

- negative compensation
- hourly wage <= 0 in hourly mode
- hours/week <= 0 in hourly mode
- weeks/year <= 0 in hourly mode
- annual salary <= 0 in salary mode
- negative percentages
- negative annual costs
- expected revenue < 0
- annual base compensation <= 0 where ratios divide by zero

Validation should be structured and field-specific where practical.

## UX

Default flow:

1. Employee type toggle: Hourly / Salary
2. Quick compensation inputs
3. Quick employer-cost inputs
4. Primary result
5. Improve accuracy / Advanced inputs
6. Cost breakdown
7. Optional revenue/productivity scenario
8. Methodology
9. FAQ

Requirements:
- real-time calculation
- no Calculate button if reliable
- advanced section collapsed by default
- responsive mobile-first design
- clear separation between compensation, benefits, and support costs
- avoid overwhelming the first viewport

## Methodology copy requirements

Explain clearly:

- base pay is not the same as total employer cost;
- employer-paid taxes, insurance, benefits, equipment, recruiting, training, and support costs can materially increase total cost;
- values vary by employee, state, insurer, company policies, and business model;
- the revenue scenario does not calculate net profit;
- the calculator provides planning and educational information, not tax, legal, accounting, insurance, HR, or financial advice.

## Unit tests required later

At minimum:

1. hourly baseline scenario;
2. salaried baseline scenario;
3. all optional annual costs = 0;
4. payroll tax = 0 and workers comp = 0;
5. decimal hourly wage;
6. large but valid values;
7. invalid hourly compensation;
8. invalid salary compensation;
9. cost multiplier calculation;
10. optional revenue scenario;
11. revenue = 0 or blank handled safely;
12. no double-counting between base pay and bonuses/benefits.
